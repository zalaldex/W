## 🚀 One-Click Deploy

Deploy your own instance of the Monospace Bot instantly using any of these free-tier friendly providers. (Make sure to replace `your-username/telegram-monospace-bot` with your actual repo link in the Koyeb and Heroku URLs).

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

[![Deploy to Koyeb](https://www.koyeb.com/static/images/deploy/button.svg)](https://app.koyeb.com/deploy?type=git&repository=github.com/your-username/telegram-monospace-bot&env[BOT_TOKEN]=&env[PORT]=8080&env[PUBLIC_DOMAIN]=&name=monospace-bot)

[![Deploy to Heroku](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy)

> **Note on Domains:** If you are not using Railway, you must paste your app's public domain (e.g., `your-app.onrender.com` or `your-app.koyeb.app`) into the `PUBLIC_DOMAIN` environment variable so the bot can properly register its Telegram webhook. Do not include `https://`.
